# 文档导航

当前版本的使用方法与验收结果分别维护；历史报告不再混入操作指南。

| 要做什么 | 阅读 |
|---|---|
| 接入组件库 | [Consumer guide](CONSUMER_GUIDE.md) |
| 查属性、默认值和交互约定 | [Public API](PUBLIC_API.md) |
| 查组件是否实现、示例入口与限制 | [Component status](COMPONENT_STATUS.md) |
| 运行 Gallery、截图、学习组件 | [Gallery](GALLERY.md) |
| 修改组件或扩展公共入口 | [Architecture](ARCHITECTURE.md)、[Native reuse](NATIVE_REUSE.md) |
| 调整主题、排版、动画 | [Design system](DESIGN_SYSTEM.md)、[Motion](MOTION.md) |
| 执行验证、测试性能 | [Validation](VALIDATION.md)、[Performance](PERFORMANCE.md) |
| 查看当前交付状态与未完成事项 | [Status](STATUS.md) |
| 查看本轮演进目标与验收要求 | [SPEC](specs/QUADRANT_KIT_FLUENT_EVOLUTION_SPEC.md) |
| 查历史证据、原始报告与版本 | [History](HISTORY.md)、[Changelog](../CHANGELOG.md) |
| 查源码与资源许可 | [Provenance](PROVENANCE.md)、[Notices](../THIRD-PARTY-NOTICES.md) |

长期执行约束在根目录及各层的 AGENTS.md；不在 SPEC 中复制模板。
新结果更新 STATUS/HISTORY；命令更新 VALIDATION；组件声明与行为更新 PUBLIC_API。
只有有独立维护价值的内容才新建文档。
