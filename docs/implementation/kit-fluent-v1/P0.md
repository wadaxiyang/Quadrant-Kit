Memory is a fixed 2s-after-Popen sample, not proven steady state. Binary size is
one build per side, repeated as metadata on process samples. Main construction
max−min spans **0.246–2.278ms** across these groups; even the two equivalent empty
groups have differing medians. This is a preliminary noise observation, not enough
to freeze a p95 gate or claim Kit is faster/smaller in general.

Import-only did not increase binary size in this setup. Hidden Toast adds
**2,264,064 bytes (2.159MiB)** versus empty, above the unadjusted proposed simple-scene
budget of max(512KiB, 5% of A). This is a real pre-change finding, **not a budget PASS**:
there is no equivalent std Toast in A, and additional code/assets are not yet
attributed. P1/P5/P7 must address applicability and attribution without silently
raising the budget. Similar/private lower samples do not establish zero hidden
cost, timer inactivity or absence of leaks.

All 36 Release runs reported the rendering notifier unsupported. Therefore
