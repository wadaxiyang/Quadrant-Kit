## Implementation and API review

IconButton and SegmentButton now have one visible std Button input owner, native
read-only state outputs and explicit names. IconButton uses builtin Tooltip and a
passive danger outline. Populated icons use native 44×32 default content geometry;
forcing a smaller width retains a native sizing limitation. SegmentButton keeps
host-selected state: checked is one-way bound, checkable is false, and accessible
checkable/checked are explicit. Neither pointer nor keyboard changes host selection.

WindowControlButton composes IconButton and forwards requests only. Back/toggle and
navigation-search names target the actual native owner. Gallery disclosure buttons
use std Button with their expandable semantics. Real Gallery chrome is unchanged.
NavigationItemRow's custom activation/traversal remains explicit P5C debt.

TextField's native editor and error border are top-aligned, with a wrapping caption
and content-driven minimum height. TextArea keeps TextEdit. PageHeader stacks its
action below 420px; header/metric/empty labels wrap. SettingRow uses a shared disabled
foreground for its own labels; Gallery binds its Switch enabled to the same host
source. SurfaceCard removes whole-subtree opacity and creates pointer/a11y helpers
only when interactive. Its arbitrary-child action exception retains one disabled
focus anchor. Default elevation stays off; no new animation/shadow or registry.
FluentIcon/Badge retain their already-small purposeful structures. The complete
21-component disposition is in COMPONENT_STATUS.md.

Exactly seven public declarations changed; the facade set and public bases did not.
Reviewed diff: `target/kit-fluent-p3/api-review.diff`. The adoption assertion required
exactly Theme, IconButton, SegmentButton, WindowControlButton, SurfaceCard,
FluentTextField and EmptyState. Changes are 8 property additions and 12 removals:
35 names, 234 properties, 20 callbacks. No unrelated baseline change was accepted.
PUBLIC_API contains current declarations and Breaking changes. Preview-only inputs,
WindowControlButton.symbol and EmptyState.milestone are removed, without aliases.
