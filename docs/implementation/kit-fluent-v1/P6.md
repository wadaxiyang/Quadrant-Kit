## Implementation and current API

Motion adds per-window host inputs animations_enabled=true and reduced_motion=false.
Its fast/standard/slow outputs resolve to 100/160/200 ms normally and 0 ms under
either disabling condition. They govern only Kit-owned motion, never the pinned
native Button's 150 ms or other native controls' animations. The full inventory
and state diagram are in [MOTION.md](../../MOTION.md).

ToastHost and ModalManager now have a shared private TransientLifetime helper in
primitives/private. It tracks hidden/entering/visible/exiting, animates only opacity
with effective standard/ease-out, and runs one cleanup timer solely in transition.
A reversal starts from current opacity and restarts cleanup; stable states stop it.
Zero duration replaces the animated target and settles synchronously, without
waiting for a nonzero timer. Own-root hide also settles immediately.

shown remains the sole logical host state. New read-only presented/animating expose
render lifetime. Toast input and automatic timeout stop on logical close; its 56 px
area is retained only through bounded exit, then collapses once. No height/layout
animation or extra blur is added. Modal native input works during entry, disables
immediately on close, restores through the existing host callback then, and
refocuses the native initial action on a retained-body reopen. Completion emits no
business or restoration callback. Full dialog/reader capability remains PARTIAL.

Native Tooltip/Flyout/Menu/date-time popup close remains native/immediate. Expander
content and InfoBar keep their existing immediate contracts; Expander's required
host-conditional slot is unchanged. No arbitrary slot factory or window service.
Gallery has a reachable Motion page with per-window native policy controls and
actual Toast/fixed-modal examples. The static facade still has 59 names / 42 visuals.
Only Motion and four new read-only overlay outputs changed API; current snapshot,
probe, docs and all native records are deliberately synchronized.
